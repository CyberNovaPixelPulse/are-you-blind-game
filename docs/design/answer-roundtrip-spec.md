## Problem Statement

普通、挑戰與多人 PK 的玩家都需要可信且一致的答題回饋。目前三種模式各自處理答案送出與結果解讀，等待期間連點、網路延遲、失敗重試及離開後才抵達的回應，可能造成重複採用結果、錯誤標記已作答，或讓 PK 計分受到網路速度影響。玩家也需要分辨答案錯誤與題目／連線異常，避免因系統問題失去連勝或取得不實成績。

## Solution

三種模式使用同一個共用答題流程，統一送出、防重複、請求逾時、驗證判定、失敗重試與過期回應隔離。只有目前作答情境中的有效判定可以被採用一次，並記為已作答。各模式保留計分、倒數、連勝、揭曉、換題與結算規則；玩家不因網路等待或紀錄儲存失敗承擔額外遊戲懲罰。題目無法判定時提供明確且符合模式的收尾。

## User Stories

1. As a 普通模式玩家, I want a 可信的正誤判定, so that 我的連勝與揭曉畫面符合實際答案。
2. As a 挑戰玩家, I want a 保留原有計分與通關規則的答題流程, so that 共用化不會改變遊戲難度。
3. As a PK 玩家, I want a 以送出答案時的作答耗時計算的分數, so that 網路等待不會降低速度加分。
4. As a 玩家, I want a 送出後立即鎖定的選項, so that 等待期間連點不會產生多個有效請求。
5. As a 玩家, I want a 失敗後沿用原選項的明確重試操作, so that 同次作答不會變成重新猜答案。
6. As a 玩家, I want a 最多等待十秒的判題請求, so that 連線異常時不會無限等待。
7. As a 玩家, I want a 與答錯分開呈現的網路錯誤, so that 失敗請求不會扣除我的遊戲成果。
8. As a 挑戰玩家, I want a 等待判定期間暫停的倒數, so that 伺服器延遲不會消耗答題時間。
9. As a 挑戰玩家, I want a 每次失敗後恢復該次送出前剩餘時間的倒數, so that 重試不會補回先前已耗掉的時間。
10. As a 挑戰玩家, I want a 等待按重試時繼續消耗的倒數, so that 重試狀態不會無限延長挑戰。
11. As a 挑戰或 PK 玩家, I want a 重試仍沿用首次送出時計分時間的結果, so that 網路問題不會改變同次作答的計分依據。
12. As a 玩家, I want a 換題、重開或離開後不再生效的舊回應, so that 舊答案不會污染新的題目與分數。
13. As a PK 玩家, I want a 切換房間後隔離的舊判定, so that 其他房間的結果不會影響目前對戰。
14. As a 玩家, I want a 題目循環後仍能正常作答的新情境, so that 曾經出現的同題不會被誤認成舊回應。
15. As a 玩家, I want a 切換介面語言後仍有效的當前作答, so that 顯示語言不會取消正在等待的判定。
16. As a 玩家, I want a 以選項識別標示的正解, so that 相同選項文字不會造成錯誤揭曉。
17. As a 玩家, I want a 拒絕錯題、錯選項或矛盾資料的流程, so that 不可信的回應不會被當成遊戲結果。
18. As a 玩家, I want a 原圖或說明缺漏時仍可採用的有效判定, so that 顯示素材問題不會迫使我重新作答。
19. As a 玩家, I want a 僅在有效判定採用後新增的已作答紀錄, so that 未完成的請求不會被算成已作答。
20. As a 玩家, I want a 與已作答分開保留的看過紀錄, so that 題目呈現與完成作答具有清楚的區別。
21. As a 玩家, I want a 紀錄或分數儲存失敗後仍保留的本機判定, so that 同題不會被重新判定或重複加分。
22. As a 登入玩家, I want a 有限且不重複的作答紀錄補送, so that 暫時性儲存失敗有恢復機會而不持續重送。
23. As a 切換帳號的玩家, I want a 停止舊帳號補送的流程, so that 紀錄不會寫入另一個帳號。
24. As a 普通模式玩家, I want a 無法判定時由我明確換題的操作, so that 題目異常不會增加或中斷連勝。
25. As a 挑戰玩家, I want a 題目異常時標明中斷且可查看已完成結果的畫面, so that 我能理解本次未通關且未提交排行榜的原因。
26. As a 每日挑戰玩家, I want a 不因中斷而自動重開或改變參與限制的流程, so that 每日挑戰規則保持一致。
27. As a PK 玩家, I want a 題目異常時停止本機作答並提供離房入口的畫面, so that 系統不會自行跳題、虛構分數或宣告勝方。

## Implementation Decisions

- 建立三種模式共用的答題往返模組，以單一公開行為介面提供送出、同選項重試、情境失效及有效判定／失敗狀態。共用層處理傳輸、防重複、驗證、錯誤分類與舊回應隔離；模式保有遊戲規則與判定採用後的模式效果。
- 首次送出立即鎖定選項；尚未取得有效判定的重試沿用該選項。同時最多一個有效請求進行，判題不自動背景重試。每次請求上限十秒，逾時與連線失敗提供玩家明確重試。
- 伺服器保有答案正誤判定責任。判題回應包含題目識別、送出選項識別、正確選項識別及布林正誤；驗證與目前題目、其選項及彼此關係一致，才可採用。不得由答案文字推導正解。
- HTTP 錯誤及無效回應不算答錯。傳輸逾時、連線失敗與無效回應可明確重試；伺服器明確指出題目已移除、選項無效或缺少正解等不可恢復問題時，回傳題目無法判定並停止相同請求重送。不得僅因圖片缺漏而分類為判題失敗。
- 作答情境包含本次題目呈現與所屬回合／房間。換題、重新開始、離開及切換房間使舊情境失效；同題循環再現也是新情境。舊回應不得採用、加分、寫紀錄或解除新請求等待。單純切換介面語言而保留題目不使作答失效。
- 同一有效判定最多採用一次。挑戰與 PK 的同次作答以首次有效送出時固定的時間計分，重試不改變；PK 排除伺服器等待時間，保留既有公式與速度加分區間，不新增答題截止。普通模式不新增時間計分。
- 挑戰每次等待判定時暫停倒數。失敗從該次請求送出前剩餘時間繼續；等待玩家按重試仍消耗時間，後續失敗不得補回先前耗時。倒數歸零依既有規則結束並使後續回應失效，與首次送出時計分時間分開處理。
- 三種模式均在有效判定採用後記為已作答，正確與錯誤皆包含。看過仍以實際呈現為準；失敗、逾時、無效及過期回應不新增已作答紀錄。
- 判定採用後的紀錄或分數儲存失敗不撤銷判定與本機結果，不重新判題或重複加分。已作答紀錄為獨立、按玩家與題目去重的操作；目前頁面工作階段內，初次失敗最多自動補送兩次，換題保留待補送項目。用盡次數時保留本機已作答狀態並提示尚未同步。登出／切換帳號停止舊帳號補送且不得改用新帳號寫入。關閉或重新整理不保證恢復。
- 排行榜及 PK 進度儲存失敗仍由模式呈現及處理，本輪不重做同步或補送。答案說明、嘲諷文字及原圖缺漏採替代顯示，圖片載入失敗不重送判題。
- 題目無法判定時，普通模式提示後由玩家明確換題，不增加或中斷連勝；挑戰停止倒數並標明中斷，保留已完成結果供查看，不算通關、不提交本次排行榜，提供返回入口，不自動重開每日挑戰或改變參與限制；PK 停止本機作答，提示異常並提供離房入口，不自行跳題、不送虛構分數、不宣告勝方，沿用既有離房處理。

## Testing Decisions

- 使用者已確認以共用答題流程公開介面作為主要測試接縫，再以少量模式整合驗證各自規則。測試外部可觀察行為，不依賴內部狀態欄位、函式拆分或呼叫順序。
- 主要測試以可控制的判題傳輸、時間及紀錄儲存協作者，驗證連點只送一次、鎖定選項重試、十秒逾時、結果識別與一致性、無法判定分類、判定只採用一次，以及顯示資料缺漏不影響採用。
- 驗證換題、重開、離開、切換房間及同題循環的過期隔離；包含舊請求失敗／成功均不得解除新請求等待，以及語言切換保留有效判定。
- 驗證僅採用後寫已作答紀錄、同玩家同題冪等、初次失敗後最多補送兩次、換題保留補送、用盡時提示、登出／帳號切換隔離；紀錄失敗不重送判題或重複套用遊戲效果。
- 普通模式整合驗證正確／錯誤各採用一次、網路失敗不影響連勝，無法判定後明確換題不改變連勝。
- 挑戰整合驗證等待暫停、每次失敗恢復該次剩餘時間、等待重試仍耗時、重試沿用首次計分時間、倒數結束後捨棄回應，以及異常中斷不通關／不上榜／不自動重開每日挑戰。
- PK 整合驗證等待連點只送一次、計分排除延遲、換題／離房隔離，以及題目異常不跳題、不虛構分數、不裁定勝負並提供離房。
- 沿用既有題池與發布流程的原生測試慣例，以及普通遊玩、題池生命週期與發布流程的瀏覽器測試慣例。真實服務與資料庫驗證僅針對實際新增的合約／持久化約束，不以模擬傳輸測試宣稱正式環境已驗收。

## Out of Scope

- 重做計分公式、挑戰通關規則、每日題單或參與限制。
- 重做排行榜／PK 進度的儲存、同步、補送或整房取消與勝負裁定。
- 新增 PK 答題截止或普通模式時間計分。
- 持久化離線佇列、跨重新整理／關閉網頁恢復補送，以及無限背景重試。
- 題池架構、題目發布與圖片清理生命週期的額外重構。
- 部署、正式資料庫變更執行及正式環境驗收。
