# 題池生命週期設計

狀態：行為與測試邊界已確認，規格已發布為 [GitHub Issue #2](https://github.com/CyberNovaPixelPulse/are-you-blind-game/issues/2)，標記 ready-for-agent；尚未實作。

完整規格見 [共用題池生命週期規格](question-pool-lifecycle-spec.md)。

## 目的與邊界

將普通遊戲與挑戰模式重複的題池生命週期集中管理：取得題目、待出題緩衝、補題、去重、合併同時發生的補題要求，以及使過期請求結果失效。保留既有抽題選擇規則，不只包裝 fetch。

各模式仍負責倒數、計分、連勝、廣告、開始與結束。每日挑戰保留指定題目來源及順序限制；圖片預載可依模式需要安排。

## 已確認行為

1. **呈現才算看過。** 預載與補題只產生待出題，不寫入看過的題目紀錄；當前題目與待出題都參與去重。詞義見根目錄 GLOSSARY.md。
2. **普通隨機題目可循環。** 優先使用未看過的題目，耗盡後允許再次使用看過的題目，仍排除當前題目與待出題。只有一題可玩時，允許連續出同一題，避免卡住。每日挑戰不套用隨機循環。
3. **切換語言從下一題生效。** 保留正在作答的題目，丟棄舊語言尚未呈現的待出題；舊請求即使較晚完成，也不得合併回新題池。
4. **允許語言補題。** 優先使用指定語言，題目不足時可補入其他語言，並保留混入其他語言的提示。每日挑戰維持指定題單，不加入隨機題目。
5. **背景失敗不打斷已有題目。** 補題失敗時仍可消耗待出題，後續再嘗試補題；只有要求下一題而題池已空時，才呈現可重試的載入錯誤。
6. **失敗與耗盡必須分開。** 暫時載入失敗不能當成沒有可出題目，也不能因此觸發挑戰通關結算；確實耗盡時由各模式決定結束行為。

## 實作驗收情境

- 同時觸發多次補題，不重複加入同一題。
- 補題成功但尚未呈現，重新讀取看過紀錄時不包含這些待出題。
- 未看過題目耗盡時能繼續一般遊戲；只有一題可玩也能前進。
- 切換語言後，舊請求較晚完成不會帶回舊待出題，也不會清掉新請求的進行狀態。
- 指定語言不足時可補入其他語言，且提示狀態與實際題池一致。
- 背景補題失敗但仍有待出題時可繼續；題池空時可重試，且不誤判通關。
- 每日挑戰維持題單來源與順序限制，不循環或混入隨機題。
- 普通模式與挑戰模式的倒數、計分、連勝、廣告與既有開始／結束規則維持原樣，以上明確同意的變更除外。
