規格：GitHub #12。工單：#14 挑戰、#15 PK、#16 已作答紀錄補送。

## 行為

- 挑戰沿用共用判題：同步鎖定首次選項、明確重試、等待暫停倒數，失敗只恢復該次請求前剩餘時間；重試等待耗時但採用首次送出的計分時間。題目無法判定時中斷，不通關、不提交排行榜、不自動重開每日挑戰。
- PK 沿用相同流程，以首次送出時間排除網路延遲；換題、離房、房間／玩家／對戰階段變更隔離舊結果及延遲換題。無法判定時停止本機作答並提供離房入口。
- 三模式採用有效判定後才記為已作答。紀錄綁定玩家身分，利用既有玩家＋題目主鍵去重，忽略重複寫入而不修改舊紀錄。每筆初次失敗後最多補送兩次，停用 SDK 額外重試，耗盡提示未同步；換題保留、本頁離開或帳號變更取消待補送與舊回應。
- 不新增資料庫結構，不改排行榜／PK 進度同步策略。

## 工作樹保留
