# Issue #8：手動發布接入

本機完成範圍：固定發布內容及識別、持久化發布紀錄與圖片意圖、同次發布安全重試、原子成立題目與結果、有限結果查詢，以及手動發布頁接入。取消、明確重審及到期清理留給 Issues #9–#11。

## 執行前提

- 新發布 API 需要先套用 `20261026110107_question_publication_lifecycle.sql`；本次未執行正式資料庫遷移、部署或排程啟用。
- 沿用既有伺服器環境設定、題目資料表、審核服務及兩個圖片儲存區。只有伺服器使用 service role；使用者身分由 Auth 驗證，再由伺服器傳入發布操作。
- 新的發布紀錄及圖片追蹤表啟用 RLS，公開角色不可讀取或呼叫服務專用操作。圖片意圖先於實際上傳保存，避免回應遺失後失去資源身分。
- 發布結果查詢不啟動審核。結果不明時不建立新識別，也不從瀏覽器刪圖。
