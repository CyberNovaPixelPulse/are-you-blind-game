# Issue #13 — 普通模式接入共用答題流程

來源：https://github.com/CyberNovaPixelPulse/are-you-blind-game/issues/13 ，父規格 #12。

## 交付

共用答題往返流程處理同步防連點、鎖定選項明確重試、首次送出時間、十秒完整請求期限、判定識別及一致性、一次採用與題目呈現失效。普通模式接入並在採用後才寫已作答紀錄；暫時失敗不影響連勝，無法判定由玩家略過，原圖缺漏保留特寫。

判題 API 額外提供題目／送出選項／正解識別，保留舊欄位以相容尚未遷移的模式；缺少有效正解不再回傳答錯。沒有新增資料庫結構。

## 範圍

#14 挑戰遷移、#15 PK 遷移與 #16 紀錄有限補送尚未實作。沒有部署、推送或修改正式資料庫。

## 驗證

- 共用公開介面與真實判題 handler（外部 Supabase HTTP 邊界模擬）測試。
- 普通模式瀏覽器測試：明確重試與略過、答錯正解標示、紀錄失敗不撤銷判定。
- 修改前普通模式頁面即有相同兩個 lint 錯誤及兩個警告；新增模組、API 與測試 targeted lint 通過。
- 僅含本次提交內容的乾淨副本：TypeScript 通過、21 個原生測試通過、17 個瀏覽器測試通過。
- 正式 build 使用本機合成 Supabase 設定驗證，不代表正式服務或資料庫已驗收。
- Standards review：0 項；Spec review 初次找到同步連點造成重試鎖定選項不一致的 P2，瀏覽器重現後修正並複查為 0 項未解決問題。
